# Security

Funkin Atlas reads third-party mod folders and archives. Treat downloaded mods as untrusted input, keep your operating system updated, and do not run a mod's scripts merely to inspect its visual resources. The standalone preview is not a security sandbox.

If you find a vulnerability, use the repository's private vulnerability reporting feature when it is enabled. Do not publish a working exploit or upload a private mod archive in a public issue. Include the affected version, a minimal synthetic input, and the expected and actual behavior. If private reporting has not yet been enabled, ask the repository maintainer for a private contact channel before sharing sensitive details.

Compatibility bugs, missing sprites, and export inaccuracies are ordinary issues unless they also create a security impact.
